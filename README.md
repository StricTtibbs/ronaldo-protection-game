# 🎮 Ronaldo Protection Game

An endless action game where you protect Ronaldo by hiring security guards and eliminating threats!

## 🎯 Game Objective

- **Protect Ronaldo** from incoming enemies
- **Hire security guards** to help defend him (costs 100💰 each)
- **Click enemies** to defeat them manually
- **Survive as many days as possible**
- If Ronaldo's health reaches 0, the game restarts (but you keep your score!)

## 🕹️ How to Play

1. **Click on enemies** to damage them and make them disappear
2. **Hire security guards** by clicking "Hire Guard" button (costs 100💰)
3. Guards automatically orbit Ronaldo and shoot at nearby enemies
4. Each day you survive, you earn **500💰**
5. Difficulty increases each day - enemies spawn faster and are stronger
6. **Pause** the game anytime with the Pause button

## 📊 Game Mechanics

- **Health System**: Ronaldo starts with 100 HP. Enemies deal damage on contact.
- **Infinite Waves**: Enemies spawn continuously and get progressively harder
- **Guards**: Each guard costs 100💰 and orbits Ronaldo, attacking enemies in range
- **Scoring**: Earn points by:
  - Defeating enemies (+50 points)
  - Clicking enemies manually (+5 points)
  - Surviving days (+100 points)
  - Passive score gain (+0.5 per frame)
- **Daily Income**: Earn 500💰 when all enemies are defeated
- **Auto-Restart**: Game automatically restarts 5 seconds after game over

## 🎮 Controls

- **Click on enemies** - Deal damage
- **Hire Guard button** - Hire a security guard (100💰)
- **Pause Game button** - Pause/Resume gameplay
- **New Game button** - Start over immediately

## 📈 Difficulty Progression

As days increase:
- Enemy spawn rate increases
- Enemy speed increases
- Enemy health increases
- Enemy damage increases
